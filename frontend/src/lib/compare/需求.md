# PDF 合同比对 — 产品需求

## 1. 背景与目标

对比「模版 PDF（招标文件）」与「正式 PDF（业主合同）」的文本差异，帮助评审人员快速定位删除、新增、修改内容，并在 PDF 页面上完成对照查看与跳转定位，提供修改内容风险等级。

## 2. 使用角色

- 合同评审人员：上传两份合同 PDF，查看差异并定位到页面位置
- 研发/测试人员：切换不同比对引擎，验证结果一致性

## 3. 核心流程

### 3.1 比对流程

1. 选择比对引擎
2. 上传模版 PDF 与正式 PDF（或使用预设测试文件）
3. 发起比对
4. 查看摘要、左右 PDF 高亮与更改列表
5. 点击变更项，跳转到对应 PDF 位置
6. 支持重新上传并再次比对

### 3.2 历史记录流程

1. 查看历史比对列表
2. 支持分页与刷新
3. 查看某条历史详情，回填结果并继续浏览

## 4. 功能需求

### 4.1 文件上传

- 必须同时提供模版 PDF 与正式 PDF
- 仅支持 PDF 格式
- 缺少任一文件时不可发起比对
- 支持重新选择文件后再次比对

### 4.2 比对结果展示

比对完成后需展示：

- 差异摘要：删除数、新增数、修改数
- 左右对照 PDF 视图
- 更改明细列表

无差异时提示「未发现差异」。

### 4.3 PDF 高亮与锚点

- 模版侧：删除/修改内容以红色高亮
- 合同侧：新增/修改内容以绿色高亮
- 修改：两侧同时出现颜色修改
- 新增内容在模版侧显示「插入点」锚点
- 删除内容在合同侧显示「删除点」锚点

### 4.4 更改列表与联动

更改列表展示删除、新增、修改三类变更。

- 点击列表项或 PDF 高亮区域，激活同一变更
- 左右 PDF 同步滚动定位到对应位置
- 修改类变更需支持原文与改文的对照展示

### 4.5 历史记录

- 支持查看历史比对记录
- 支持分页
- 支持查看详情并回填结果

### 4.6 比对选项

系统默认支持：

- 忽略空白差异
- 忽略页眉页脚差异

（当前可不对用户开放配置入口）

## 5. 界面要求

- 中文界面
- 上传区明确区分「模版（招标文件）」与「正式（业主合同）」
- 结果区布局：摘要 → 左右 PDF → 更改报告
- 颜色语义统一：红=删除，绿=新增，蓝=锚点，黄色=修改

## 6. 非功能要求

- 比对过程中需有明确加载状态
- 上传失败、比对失败需有可见错误提示
- 纯前端比对不得明显卡死页面
- 仅要求支持带可选中文本的 PDF；扫描件/OCR 不在本期范围
